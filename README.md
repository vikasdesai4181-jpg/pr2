# Student Profile Card — Practical 2

A React application demonstrating reusable functional components, props, destructured props, and JSX. Student data is passed into a reusable `StudentCard` component and styled with Tailwind CSS.

## Requirements

- Node.js and npm

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Student entries are defined in `src/App.jsx`; the reusable card component is in `src/components/StudentCard.jsx`.

## Check the project

```sh
npm run lint
npm run build
```
